errors

The code every refusal carries, by what the caller does next. A code keeps its meaning through 8.x

try {
  await encode(picture);
} catch (error) {
  if (error.code === 'JXL_INPUT') showMessage(error.message);
  else throw error;
}

the call

Fix the options.

  • JXL_OPTIONS

    An option is unknown or its value is not allowed.

the input

Change the input.

  • JXL_INPUT

    The picture or bytes are missing, empty, not what the call takes, or a file that changed while it was read.

  • JXL_DIMENSIONS

    The picture is over maxPixels or the side limit.

  • JXL_JPEG

    The bytes are not a JPEG.

  • JXL_DECODE

    The file is not a valid JPEG XL.

  • JXL_RECONSTRUCTION

    No JPEG reconstruction data.

  • JXL_TARGET

    A measured fidelity this version cannot reach.

  • JXL_PLATFORM

    An input this realm cannot decode, or a host API this call needs, a missing decoder's message names configureDecoder or the effort that runs here.

a bound

Raise the bound or send less.

  • JXL_MEMORY

    Not enough memory for this picture here, or the queue's maxPendingBytes, maxPendingJobs.

  • JXL_LIMIT

    A parser's maxInputBytes or maxBytes, a written file over its byte bound, or capture's rectangle budget.

the host

Set up the host.

  • JXL_WASM

    No WebAssembly with SIMD here.

  • JXL_WEBGPU

    Webgpu: 'required' and a job this version would run on WebAssembly: efforts 1-6, an exact file, no usable device, a device that failed the job, or a route this version runs on WebAssembly only.

  • JXL_WORKER

    The worker could not start, stopped or failed, its message names the fix: a blocked worker-src, a start that timed out.

  • JXL_IO

    A Blob or an image request could not be read.

the lifecycle

Check how the call or module was closed.

  • JXL_CLOSED

    The module's queue is closed.

not done by this version

Ask for something this version does.

  • JXL_UNSUPPORTED

    A valid request or file asking for something this version does not do.

ours

Report it.

  • JXL_INTERNAL

    A fault in jpegxl itself.

the setup commands

  • JXL_SETUP

    add or remove cannot change a project's files safely. Its message names the step to do by hand.
