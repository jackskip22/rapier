shared options

These options mean the same in every function that takes them. Each function's page lists its own options first and links here for the rest.

Options

options

  • signal? AbortSignal | undefined

    Aborting before this call's promise settles rejects it with the signal's reason. Share one AbortController's signal among calls to cancel them together. A call whose promise has already settled keeps its result.

  • onProgress? ((fraction: number) => void) | ((fraction: number) => PromiseLike<void>) | undefined

    Called with 0 when the job starts, rising to 1 before the result. A throw or rejection cancels the job.

  • maxPixels? number

    Most pixels the call admits. None by default. Larger refuses JXL_DIMENSIONS.

  • onPreview? ((preview: ImagePreview) => void | PromiseLike<void>) | undefined

    Called with the latest complete candidate file, at most every 100 ms, while the encoder searches.

  • readAs? ReadAs

    Space a canvas, bitmap or Blob is read in: 'srgb' or 'display-p3'. If omitted, sRGB or the source's own. Pixels you pass say their own.

  • webgpu? 'required' | false

    Left out: use WebGPU where it helps (the result's usedWebGPU says whether it did). 'required' refuses with JXL_WEBGPU any job that would run on WebAssembly: efforts 1-6, exact files, and efforts 7-9 with no usable device. false never asks for a device.
