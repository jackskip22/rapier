jpegxl command line

Encode images to JPEG XL (.jxl), or restore recompressed JPEGs. JPEGs are recompressed losslessly by default and restore exactly.

RunOptionsJSONHelp text

run

npx jpegxl <file|folder...> [options]
npx jpegxl photo.png                   # photo.jxl alongside
npx jpegxl scan.jpg                    # lossless: JPEG restores exactly
npx jpegxl photos/ --out dist/         # every PNG, JPEG, WebP, AVIF, GIF, HDR and EXR in the folder
npx jpegxl hero.png --max-bytes 100KB  # best quality that fits
npx jpegxl scan.jxl --out back/        # back/scan.jpg, original JPEG

Options:

options

  • --quality <1-100> -q

    Target quality (default 90, and a JPEG stays exact)

  • --effort <1-10> -e

    Encoding effort, 1 fastest to 9 smallest, 10 with --exact (default: 7)

  • --max-bytes <size>

    Fit output under byte budget (e.g. 80KB, 1.5MB, 120000)

  • --exact

    Every pixel kept (default for JPEG)

  • --jpeg-pixels

    Re-encode JPEG pixels, retaining no JPEG reconstruction

  • --out <path> -o

    Output file or directory

  • --jobs <0-16> -j

    Helper worker threads (default: 0)

  • --verify

    Verify each output before writing it

  • --json

    One JSON line per file, then a summary

  • --help -h

    Show this help

  • --version -v

    Show version

Usage: jpegxl <file|folder...> [options]
       jpegxl add emdash | astro | vite | webpack | next | netlify | workers | r2 | agents | android | ios | flutter | expo | electron | tauri
       jpegxl add                 lists every place, one line each
       jpegxl remove <integration>
       jpegxl selftest
       jpegxl verify <original|folder> <file.jxl|folder>

Encode images to JPEG XL (.jxl), or restore recompressed JPEGs.
JPEGs are recompressed losslessly by default and restore exactly.

Options:
  -q, --quality <1-100>    Target quality (default 90, and a JPEG stays exact)
  -e, --effort <1-10>      Encoding effort, 1 fastest to 9 smallest, 10 with --exact (default: 7)
      --max-bytes <size>   Fit output under byte budget (e.g. 80KB, 1.5MB, 120000)
      --exact              Every pixel kept (default for JPEG)
      --jpeg-pixels        Re-encode JPEG pixels, retaining no JPEG reconstruction
  -o, --out <path>         Output file or directory
  -j, --jobs <0-16>        Helper worker threads (default: 0)
      --verify             Verify each output before writing it
      --json               One JSON line per file, then a summary
  -h, --help               Show this help
  -v, --version            Show version

Examples:
  npx jpegxl add emdash
  npx jpegxl selftest
  npx jpegxl photo.png
  npx jpegxl photo.jpg
  npx jpegxl scene.exr
  npx jpegxl photos/ --effort 6 --jobs 4
  npx jpegxl hero.png --quality 82 --out dist/hero.jxl
  npx jpegxl banner.png --max-bytes 100KB
  npx jpegxl photo.jxl --out restored.jpg
  npx jpegxl verify photos/ out/
