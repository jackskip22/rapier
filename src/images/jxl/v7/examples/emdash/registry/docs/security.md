The JPEG XL Image Optimizer Registry companion displays setup instructions. It requests no capabilities and does not read media, contact external services, or store site data.

The separate native integration runs inside the site with the storage access configured by its operator. It verifies image results before publication, binds work to the original generation and delivery choice, and preserves exact JPEG reconstruction before replacing a stored JPEG with its archive. Other formats retain their original file.

Native removal requires `plugins:manage`. The CLI uses the installed EmDash public client, the matching unexpired login or an explicit `EMDASH_TOKEN`, and HTTPS for remote origins. It changes the config only after reading a saved restoration proof for the same site, storage scope and removal operation with zero remaining JPEG archives and no active writer. Blocked or ambiguous restoration leaves the integration configured. Removing the Registry guide alone has no image-storage effect.

Report security concerns to hello@rapier.website. Send a concise description without passwords, access tokens or private images.
