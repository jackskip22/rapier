# Carlito

Carlito supplies Calibri-compatible metrics in DOCX layout when Calibri is not installed. It is loaded with the document part.

Source: Debian trixie's `fonts-crosextra-carlito` package, upstream https://github.com/googlefonts/carlito. Regular, bold, italic and bold italic were losslessly packaged as WOFF2 with FontTools. No glyphs or metrics were changed. The original copyright and SIL Open Font License are in `LICENSE` and the app's font notices.
